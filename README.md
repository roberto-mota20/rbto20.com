# rbto20.com

Página pessoal, links e módulo de publicações **memd** ([rbto20.com](https://rbto20.com)), construída com HTML, CSS e JavaScript puros e hospedada no Cloudflare Workers.

## Módulo memd

Para adicionar novas publicações em Markdown (`.md`) ou MDX (`.mdx`):
1. Adicione o arquivo na pasta `publicacoes/` (ex: `publicacoes/meu-artigo.md`).
2. Adicione os metadados no `publicacoes/manifest.json`.
3. Acesse em `/memd` ou diretamente via `/memd?post=meu-artigo`.
